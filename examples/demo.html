Open-source ornament library

Medieval ornaments for the web

Borders, decorations and illustrations based on historical ornament plates and manuscripts, plus newly authored pieces. Use them as CSS frames, repeating dividers or images, with plain CSS, JavaScript or React.

Browse the gallery See how to use them
npm i @ranx729/medieval-ornaments

What’s inside

Every design comes as PNG and lossless WebP in several sizes. Floral borders and plate traces are also available as SVG. Each design records how it was made.

Borders

Repeating patterns with matching corners, for frames and dividers.

Decorations

Panels, corners, roundels, headpieces and flourishes, used as whole images.

Illustrations

Animals, musicians, flowers and scenes from manuscript margins.

Usage

Three ways to use them

Each example is live. Pick a design and copy the code: it is exactly what you would write in your own project.

Frame any element

One image supplies the corners and the repeating edges. The frame follows its content at any size.
