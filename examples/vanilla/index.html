Integration

Plain JavaScript

Attach a frame, a divider or an image to any element. Each controller picks the right artwork for its size and can be updated or removed later. No framework required.

npm i @ranx729/medieval-ornaments

Borders: frames and dividers

Every border works as a frame around any element and as a divider in either direction. Changes call update() on the same controllers.

Import a single design
For a fixed selection, import each design directly. Your bundle then contains only that design’s metadata, and the design option is not needed.

    

      

      
import { createDivider }
  from '@ranx729/medieval-ornaments/designs/red-berry-vine';
import '@ranx729/medieval-ornaments/styles.css';

createDivider(document.querySelector('.divider'));

      

      
import { createOrnamentImage }
  from '@ranx729/medieval-ornaments/designs/flying-pig';

createOrnamentImage(document.querySelector('img'), {
  size: 128, loading: 'lazy', decoding: 'async'
});
