# Medieval ornaments

Reusable painted decorations and editable border designs, with PNG, lossless WebP, and smaller raster sizes. This repository is separate from [medieval-cutouts](https://github.com/adrian729/medieval-cutouts).

- **5 painted vertical ornaments:** transparent, AI-assisted extractions from the supplied reference. These are complete decorations, not seamless repeat tiles.
- **6 border styles:** original SVG reconstructions inspired by the supplied floral border sheet.
- **38 numbered plate designs:** SVG adaptations named after their original plate numbers, plus exact raster reference crops. Reconstructions simplify the painted artwork; they are not exact tracings. Corners are new adaptations.

All 44 vector border styles include a repeat tile, a corner, and a nine-slice border atlas. The atlas works on rectangular frames of different sizes. Use the reference crops when the original painted appearance matters; use the vectors when repeating, resizing, or editing matters. Reference crops are not declared seamless.

## Preview and use

Run `python3 -m http.server 8765` in this folder and open [the interactive preview](http://localhost:8765/examples/). Choose a design, change the frame size and border thickness, switch between SVG/PNG/WebP, and inspect the original reference where available.

```html
<img src="https://raw.githubusercontent.com/adrian729/medieval-ornaments/main/webp/256/floral-bird-panel-blue.webp"
     alt="" height="256">
```

For a scalable frame:

```css
.decorated {
  border: 32px solid transparent;
  border-image-source: url("https://raw.githubusercontent.com/adrian729/medieval-ornaments/main/svg/red-berry-vine-border.svg");
  border-image-slice: 21.42857142857143%;
  border-image-repeat: round;
}
```

`round` fits whole repeat units into each edge; `repeat` keeps their proportions and can clip a unit at the ends. Corners rotate the same adapted corner around the frame. These are deliberate turns rather than extensions of every motif through the corner. See [usage details](USAGE.md) and [selection guidance for LLMs](SELECTION.md).

## Formats and sizes

`images.json` is the machine-readable catalog. `png/` and `webp/` contain masters; subfolders `128/`, `256/`, `512/`, and `768/` contain variants whose longest dimension is that size. A variant exists only when smaller than its master. Every size is made directly from the master; original raster artwork is never enlarged. SVGs are resolution-independent. Their raster masters are rendered at a longest dimension of 1024px, then reduced.

Painted ornament PNGs retain transparent backgrounds and are capped at the supplied image's 650px height. Exact reference crops retain their original paper/background; the two L-shaped corner crops mask neighboring designs. PNG and WebP pairs have identical dimensions, alpha, and visible pixels.

## Maintain the collection

Read [AGENTS.md](AGENTS.md) before editing. Install and regenerate:

```sh
python3 -m venv --system-site-packages .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python scripts/build_assets.py
.venv/bin/python scripts/catalog.py
.venv/bin/python scripts/catalog.py --check
```

The five extraction prompts and method are recorded in [EXTRACTION-PROMPTS.json](EXTRACTION-PROMPTS.json). Reference crop coordinates are in [reference-crops.json](reference-crops.json). Asset metadata records whether a file is an extraction, reconstruction, or reference crop. This repository does not establish ownership or a blanket license for the supplied reference artwork; no source attribution has been invented. The vector code and exported assets are provided without a blanket license until provenance is established.

[Quality checks](QA.md) cover every exported file and all formats in the browser preview.
